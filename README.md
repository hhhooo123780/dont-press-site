# 絶対に押すな｜無駄クリック選手権

スマホ向けの静的サイトです。共通カウント、今日・週間・累計ランキング、全員ボス、レアイベントはSupabaseの実データを使います。Supabaseを設定しない間は共通値を「集計準備中」とし、数字を作りません。

## 公開までの設定

1. GitHubで空の公開リポジトリを作り、このフォルダーの中身を `main` ブランチへ push します。
2. GitHubの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。`main` へのpush後、ActionsのPagesワークフローが成功すれば公開されます。
3. Supabaseでプロジェクトを作成し、SQL Editorで `supabase/schema.sql` を一度実行します。FreeプランにはDB容量・通信量・Realtime接続/メッセージの上限があり、1週間非稼働でプロジェクトがpauseする場合があります。GitHub PagesはGitHub Freeの公開リポジトリで利用できます。Supabaseの現行料金・枠を確認し、有料プランへ自動変更しないでください。
4. SupabaseのProject URLとpublishable/anon keyを `site-config.js` に入力します。`service_role` キー、DBパスワード、秘密鍵は絶対に入力しないでください。ブラウザーキーは公開される前提で、テーブルへの直接アクセスをRLSで禁止し、許可したRPCだけ使います。
5. 設定をcommit/pushするとGitHub Actionsが再公開します。独自ドメインを使う場合はGitHub Pagesの設定から登録します。

## 防止策と限界

- フロント側はクリック送信を約0.85秒単位でまとめ、サーバーはvisitor IDごとに0.7秒の間隔と1リクエスト100クリック上限を適用します。
- ランキングには名前やメールアドレスを保存せず、ブラウザーに発行したランダムIDの短い匿名コードを表示します。
- 静的公開サイトではログインやCAPTCHAなしに強固なbot防止はできません。攻撃者がIDを変える水増しは完全には防げません。異常値が問題になったら認証・CAPTCHAまたはEdge Functionを追加してください。
- 「いまクリックしている人数」は厳密に測れないので表示しません。オンライン人数もクリック中人数として誤表示しません。端末内IDをリセットしてもサーバー上の過去クリックは累計に残ります。
- 集計RPCはデータが増えると重くなる可能性があります。利用が伸びたら日別集計テーブルへ移行してください。

## 収益枠の編集

- アフィリエイトURL: `site-config.js` の `affiliateLinks` にタイトル・説明・HTTPS URLを追加します。公開前に各ASPの表記ルールに従い、現在の「広告・アフィリエイト」表示を維持してください。
- ディスプレイ広告: 提携先が発行した公式スクリプトURLと必要なスロットIDのみを `displayAdScriptUrl` / `displayAdSlotId` に設定します。秘密情報を含むタグは置かないでください。提供元のタグ形式がURLだけで使えない場合は、その提供元に合わせた実装が必要です。
- 休憩動画: 利用許諾のあるHTTPS MP4/WebMを `sponsorVideoUrl` に設定します。5〜15秒の動画だけ再生し、動画がなくても休憩を閉じてゲームを続けられます。

## 動作確認

`python3 -m http.server 8000` を実行し、スマートフォンまたは開発者ツールのモバイル表示で確認できます。ローカルでSupabase未設定なら「集計準備中」と表示され、クリック・個人記録・コンボ・X共有・休憩表示のみ動作します。全国カウント、ランキング、レアイベント、Realtimeを検証するには、Supabase SQLを適用した設定が必要です。
